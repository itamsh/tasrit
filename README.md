# תצוגת תשריטים | מבא"ת

כלי חינמי לצפייה וניתוח תוכניות בנייה ישראליות (תב"עות / תמ"ל) — פועל ישירות
בדפדפן, ללא התקנה, ללא שרת, ללא חשבון.

🔗 **[tasrit.vercel.app](https://tasrit.vercel.app)**

## מה הכלי עושה

- מציג תשריט גרפי אינטראקטיבי מקבצי SHP של מבא"ת — לחיצה על תא שטח מציגה את
  ייעודו, שטחו ומידותיו.
- טוען תשריט **ישירות לפי מספר תוכנית**, בלי להוריד קבצים בכלל (דרך שירות
  ה-GIS הפתוח של מינהל התכנון).
- מנתח קובץ "טבלה 5" (זכויות והוראות בנייה) ומציג אותו יחד עם התשריט.
- בודק תאימות לתמ"א 35/4, מחשב רח"ק וצפיפות, ומאפשר בניית רשת דרכים.
- מפת רקע גאוגרפית (תצלום אוויר / רחובות) מיושרת לקואורדינטות התוכנית.
- שומר כמה תוכניות כ"פרויקטים" נפרדים, ישירות בדפדפן — בלי שרת ובלי חשבון.

## טכנולוגיה

קובץ HTML יחיד, JavaScript רגיל (ללא framework, ללא build step). כל העיבוד
קורה בדפדפן של המשתמש — שום נתון לא נשלח לשרת, למעט קריאות לשירותי מפות
ציבוריים (מינהל התכנון, Esri).

## זכויות

הקוד גלוי לצפייה כאן ב-GitHub, אך **כל הזכויות שמורות** — אין רישיון קוד
פתוח, ואין רשות להעתקה, הפצה או שימוש חוזר ללא אישור מפורש.
